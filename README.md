# Enderman Tower Bait Protection

For Minecraft 1.20.1 / NeoForge 47.1.106 / L2 Hostility 2.5.19.

The mod cancels only `l2hostility:killer_aura` damage received by
`minecraft:endermite` entities carrying the `enderman_tower_bait` tag.

It does NOT set Invulnerable, alter teams, alter AI, or change Enderman targeting.

## Build
Use Java 17 and Gradle:
`gradlew build`

Output:
`build/libs/enderman_tower_bait_protection-1.0.0.jar`
